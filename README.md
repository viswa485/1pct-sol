# 1% BATTERY ($1PCT)

**The future is updating. Your bills aren't.**

1% BATTERY is an internet-culture project built around the feeling of trying to navigate modern life with 1% battery left. Its themes are economic pressure, AI and the future of work, and cybersecurity and online safety.

> **Project status:** The repository contains a pre-launch landing-page prototype. No verified token contract, live market, token supply or liquidity is published on the site. The site intentionally has no X or Telegram links configured.

## Project identity

- **Brand:** 1% BATTERY
- **Ticker:** $1PCT (project-selected symbol; verify the mint address before any token interaction)
- **Community concept:** The 1% Club
- **Network / launch platform concept:** Solana / Pump.fun
- **Tagline:** The future is updating. Your bills aren't.

The project is intended to use humour and community participation to explore three themes:

1. **ECON.EXE** — rent, salaries, job hunting, subscriptions and everyday costs.
2. **AI.EXE** — AI tools, changing skills and the future of work.
3. **CYBER.EXE** — phishing, fake job offers, deepfakes and digital safety.

## What's in this repository

- `index.html` — a single-file, responsive Windows 95-inspired desktop experience.
- Clickable desktop shortcuts for `ECON.EXE`, `AI.EXE`, `CYBER.EXE`, Meme Lab, The 1% Club and project information.
- Window controls for opening, focusing, minimizing, maximizing and closing apps; draggable windows on larger screens.
- A Windows-style Start menu, taskbar, open-window buttons and clock.
- A local monthly money calculator, a local-only educational scam-warning pattern check, a copyable AI prompt and a canvas meme generator.

The site uses plain HTML, CSS and JavaScript. It has no package manager, build command, external JavaScript dependency or server-side requirement. X and Telegram links are intentionally not included.

## Run locally

Open `index.html` directly in a browser, or run:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Interactive apps

- **ECON.EXE:** Enter monthly income and expenses to calculate an estimated remainder. Values are processed in the browser and are not sent to a server.
- **AI.EXE:** Read practical ways to approach changing AI tools and copy a career-workflow prompt.
- **CYBER.EXE:** Check pasted text for a small set of common scam-warning patterns. The check runs locally and is educational only; it is not a security verdict.
- **Meme Lab:** Edit preset or custom captions and download a PNG generated in the browser.
- **The 1% Club:** Complete a personal Battery Check and copy it for sharing.

## Editing and contributing

For a simple content or design change:

1. Edit `index.html`.
2. Test it locally at desktop and mobile widths.
3. Check every navigation link and interactive control.
4. Commit the change to the `main` branch.

Keep the site lightweight and accessible. Use original artwork or assets that the project has permission to use.
