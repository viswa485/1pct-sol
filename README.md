# 1% BATTERY ($1PCT)

**The future is updating. Your bills aren't.**

1% BATTERY ($1PCT) is a Solana meme-token project built around the feeling of navigating modern life with 1% battery left. The 1% Club uses humour and useful, browser-based resources to explore three everyday themes: money pressure, AI and the future of work, and digital safety.

## Project identity and content

The project uses internet culture to make everyday topics approachable:

1. **ECON.EXE** — rent, salaries, job hunting, subscriptions and everyday costs.
2. **AI.EXE** — AI tools, changing skills and the future of work.
3. **CYBER.EXE** — phishing, fake job offers, deepfakes and digital safety.

The tagline is **“The future is updating. Your bills aren't.”**

## Website features

- A responsive, Windows 95-inspired desktop with a Start menu, taskbar, live clock and app windows.
- **ECON.EXE:** a monthly income-and-expense calculator. Values are processed locally in the browser.
- **AI.EXE:** practical AI and career guidance with a copyable prompt.
- **CYBER.EXE:** a local-only educational warning-pattern check for pasted text. It is not a security verdict or malware scanner.
- **Meme Lab:** an in-browser caption generator that exports a PNG.
- **The 1% Club:** a personal Battery Check prompt and community guidelines.
- **1PCT Info:** project identity, launch context and risk disclosures.

The website does not require a wallet connection, does not collect the calculator or checker inputs, and must never ask visitors for a seed phrase, private key or one-time code.

## Run locally

Open `index.html` in a browser, or run:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

The site is a self-contained HTML, CSS and JavaScript project. It has no package manager, build step, external JavaScript dependency or server-side requirement.
